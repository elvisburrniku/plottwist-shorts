Privacy Policy

Last updated: 17 November 2026

Plot Twist Shorts is a personal tool used only by its owner, on the owner's own computer.

What it uses

When the owner signs in with TikTok, the tool receives the TikTok account's basic profile (open ID, username, display name) and an access token allowing it to post videos to that account. It uses these only to post the owner's videos and to show the owner the link to each post.

Where it is kept

The access token and post records are stored only on the owner's computer. Nothing is sent to any server other than TikTok's and YouTube's own APIs.

Sharing

No data is sold or shared with anyone. There are no ads, analytics or tracking.

Deleting

Disconnecting the app in TikTok's settings (Security and permissions → Manage app permissions) revokes its access. Deleting the token file on the owner's computer removes the stored data.
